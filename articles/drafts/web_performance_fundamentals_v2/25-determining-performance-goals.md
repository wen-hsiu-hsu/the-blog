# 設定效能目標：三個決定網站「夠快」的指標

## 不是你說了算

講師直接點明：你不能自己決定「四秒夠快了」然後就此打住，因為你的使用者不一定同意。真正決定「夠快」的有三個力量：**使用者體驗**、**競爭對手**、以及 **SEO 排名**。

## 一：使用者體驗與商業指標的關係

要理解使用者體驗在告訴你什麼，你需要看的不是效能指標本身，而是**你的商業指標**。跳出率、頁面停留時間、加入購物車的頻率、購物車放棄率、轉換率、捲動深度……這些是你的網站衡量成功的方式。

接著，你要把這些商業指標和效能指標**放在同一條時間軸上比較**，找出兩者之間的關聯。

講師展示的圖表案例說明了這個方法：當 CLS 分數升高（版面位移變嚴重）的時段，Session Time 明顯下降；當 LCP 升高（最大元素渲染變慢）的時段，Bounce Rate 跟著上升。這在直覺上都說得通：頁面跳來跳去讓人沮喪，頁面感覺很慢讓人直接離開。

但講師特別強調：**別人資料中的相關性不等於你的相關性，相關性也不等於因果關係**。他舉了一個對他來說是「最愛的圖表」的例子：全球平均氣溫與海盜數量之間有完美的負相關。資料是真實的，相關性是存在的，但顯然不是「消滅海盜導致地球暖化」。你需要對自己網站的資料做相同的謹慎解讀，找出屬於你的真實關聯，而不是直接套用別人的案例研究。

## 二：競爭對手

你的競爭對手也是決定你需要多快的因素。如果使用者會直接或間接地比較你的網站與競爭對手，你就需要考量差距。

重要的參考點是 **Weber's Law（韋伯定律）**，也稱為 20% 法則：人類通常需要兩個事物之間有約 20% 的差異，才能感知到不同。

講師用一個視覺範例說明：從 10 個點增加到 20 個點，一眼看出差距；但從 110 個點增加到 120 個點，同樣多了 10 個，卻幾乎看不出來，因為比例差距不夠大。

回到效能的比較：如果 Target 的 LCP 只比 Walmart 快 4%，使用者根本感覺不到差異，對搜尋排名的影響可能也有限。但如果 Target 的 LCP 比 Kmart 快 57%，使用者就會明顯感覺到差距，並傾向留在更快的網站。

**你不需要比競爭對手快很多，但你需要快到讓使用者能夠感知到。**

## 三：SEO 排名

第三個力量是 Google 的搜尋排名。如果你認為自己的內容與競爭對手同樣優質，卻排不進前幾名，Core Web Vitals 很可能是原因。

Google 對三個核心指標各有明確的評分門檻：

| 指標 | 良好       | 需要改善     | 差         |
| ---- | ---------- | ------------ | ---------- |
| LCP  | 2.5 秒以內 | 2.5 至 4 秒  | 超過 4 秒  |
| CLS  | 0.1 以下   | 0.1 至 0.25  | 超過 0.25  |
| INP  | 200ms 以內 | 200 至 500ms | 超過 500ms |

達不到「良好」門檻，就會在搜尋排名上受到懲罰。

## 小結

設定效能目標時，同時問這三個問題：

- 我的商業指標顯示哪些效能問題正在影響使用者行為？
- 我的競爭對手比我快多少？差距是否足以讓使用者感知到？
- 我的 Core Web Vitals 是否達到 Google 的「良好」門檻？

這三個力量共同決定你的網站需要多快，也決定了你應該優先處理哪個指標。

## 複習

### 根據韋伯定律，網站需要快多少，使用者才能感知到差異？

大約快 20%

### 決定網站是否「夠快」的三個關鍵因素是什麼？

使用者體驗、競爭對手，以及 SEO 搜尋排名

### 哪些商業指標可以用來評估網站效能？

跳出率、頁面停留時間、加入購物車次數、購物車放棄率、轉換率、捲動深度

### Google 使用哪三個 Core Web Vitals 指標來影響搜尋排名？

LCP（最大內容繪製）、CLS（累積版面位移）與 INP（互動到下一幀繪製）

### 應該如何將網站效能與商業成功連結起來評估？

將網頁效能指標與商業指標對照，找出效能分數與關鍵商業指標之間有意義的關聯
